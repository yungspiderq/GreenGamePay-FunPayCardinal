# Изменения

## 1.3.1 — 2026-11-06

- Список «Мои лоты» загружается с FunPay при открытии, добавлена кнопка принудительного обновления.
- Перед настройкой, сохранением и командной привязкой лот проверяется по свежему профилю.
- Новые лоты добавляются в основной профиль Cardinal для распознавания событий заказов; неактивные исторические лоты сохраняются.
- При ошибке обновления остаются прежний список и настройки; отсутствующий в профиле лот не объявляется удалённым.
- Соединения SQLite закрываются после каждой операции, включая ошибки, чтобы не удерживать файл базы на Windows.
- 156 автоматических тестов; дополнительная проверка с настоящими UserProfile и обработчиком определения лота Cardinal.

## 1.3.0 — 2026-11-06

- Контроль минимального баланса GreenGamePay с отдельными порогами USD и TON через кнопки.
- Реальное снятие настроенных лотов FunPay с продажи при балансе ≤ порога: периодически, после покупки и вручную.
- Проверка состояния FunPay после сохранения; повтор неудачного снятия; ошибки API не считаются нулевым балансом.
- Устойчивые к перезапуску запреты автовосстановления Cardinal и уведомления Telegram без ежеминутного повторения ошибок.
- Возврат снятых лотов по кнопке после новой проверки баланса; ранее выключенные лоты не активируются.
- Тестовый режим без изменений FunPay, контроль по умолчанию выключен. 144 автоматических теста.

## 1.2.0 — 2026-11-06

- Понятные суммы пополнения и примеры «1 штука → 100 RUB; 2 штуки → 200 RUB».
- Калькулятор заказа без обращения к поставщику с общей для калькулятора и реальной покупки проверкой объёма.
- Локальная проверка готовности и конфликтов автовыдачи; заказы с выдачей самого FunPay не закупаются повторно.
- Пауза отдельных лотов без удаления настроек; принятые заказы продолжают обработку.
- Сводка по всему журналу и поиск старых заказов по номеру.
- 100 автоматических тестов. Формат журнала и старые настройки совместимы.

## 1.1.0 — 2026-11-06

- Меню с inline-кнопками, статусом и переключателями в стиле стандартных панелей Cardinal.
- Пошаговые мастера подключения и настройки лотов без JSON; сохранение после проверки сводки.
- Списки лотов, заказов и каталога с переключением страниц; статусы и подсказки по-русски.
- Подтверждение перехода к реальным покупкам; защита от устаревших кнопок и доступа из чужого чата.
- Истечение и отмена ввода, удаление сообщения с паролем, совместимость с состояниями Telegram-бота Cardinal.
- Ручное закрытие записи больше не позволяет отправить сообщение, будто поставщик подтвердил оплату.
- 81 автоматический тест, включая сценарии кнопок и все четыре мастера лотов.

## 1.0.0 — 2026-11-05

- Первый релиз для sidor0912/FunPayCardinal.
- Steam по логину, Stars, Premium и подарки Steam через документированные API.
- Telegram-команды, привязки к лотам, подтверждение получателя и тестовый режим.
- SQLite-журнал, блокировка второго процесса, контроль повторных событий и ручная проверка неопределённых платежей.
- Тесты обработки заказов и HTTP-клиента; проверка загрузчика Cardinal.
- Ограничения контрактов Premium и подарочных кодов описаны в README.
